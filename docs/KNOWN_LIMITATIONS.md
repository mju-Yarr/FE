## 알려진 한계

### 1. 기상청 자외선지수(UV) API 엔드포인트 폐기

| 항목 | 내용 |
|---|---|
| **현재 상태** | UV 지수 조회 실패 — `400 NO_OPENAPI_SERVICE_ERROR` (reason 12) |
| **원인** | 공공데이터포털의 생활기상지수 서비스가 V4에서 V5로 전환됨. 제출 코드는 V4 엔드포인트를 사용 중 |
| **영향 범위** | 웰니스 엔진의 UV 입력이 `-1`(fallback)로 채워짐. 자외선 기반 행동 추천 정확도 저하 |
| **해결 방향** | `application.yaml`에서 URL 1줄 변경 (`LivingWthrIdxServiceV4/getUVIdxV4` → `LivingWthrIdxServiceV5/getUVIdxV5`) |
| **변경 파일** | `src/main/resources/application.yaml` (BE) |
| **변경량** | +1/-1 (1줄) |
| **검증** | 후속 저장소에서 V5 직접 호출 시 `200 OK`, 실제 UV item 반환 확인. BE 전체 300 tests 통과 |
| **미적용 사유** | V4가 제출 시점(8/21 10:00)에 정상 동작했다는 로그 미확보. 7/27 항목 수정일 기준으로 제출 전부터 실패했을 가능성 있음 → 복구가 아닌 개선으로 분류될 위험 |

**diff:**
```diff
-      index-url: https://apis.data.go.kr/1360000/LivingWthrIdxServiceV4/getUVIdxV4
+      index-url: https://apis.data.go.kr/1360000/LivingWthrIdxServiceV5/getUVIdxV5
```
